Data Description

  • Author: 待確認
  • Date first created: 20261017
  • Background: 2024 年臺北市 YouBike 2.0 站點即時車位歷史紀錄（交通部 TDX 平臺），只保留研究範圍（臺大／公館一帶多邊形）內的 78 個站點。本組研究臺大周遭站點的車輛數最適化調度，這份資料提供各站可借車數與可還空位的時間序列。
  • Unit of observation: 站點 × 來源更新時間（StationUID × SrcUpdateTime），一列為一次站點狀態更新；兩者組合唯一。
  • Sample period: 2024-01-01 00:01 至 2024-12-31 23:59（Asia/Taipei）；366 天中 356 天有資料。
  • Known issues:
    • 10 天沒有資料：2024-10-31、11-01、11-02、11-03、11-07、11-08、11-09、11-10、11-11、12-10。原始檔為空或只有範圍外站點，不是處理時刪除的。
    • 紀錄頻率不一致：2024-01-01 至 01-13 約每 1 分鐘一筆（每天約 100,000 列）；其餘日期大致只在站點狀態變動時才有紀錄（同站相鄰兩筆的間隔中位數約 2 分鐘，90% 分位約 10 分鐘），每天約 18,670 列。計算平均車數或使用頻率前，應先整理成固定時間間隔（例如每 10 分鐘取最後一筆狀態）。
    • ServiceStatus 已重新編碼：原始資料有未列於 OAS 規格的代碼 2（19,962 列），依組員對照資料網站確認改為「停止營運」。停止營運時車數仍有數值（平均可借 1.4 輛），分析時通常應排除或另行處理。
    • AvailableRentBikes 幾乎總是等於 GeneralBikes + ElectricBikes，只有 2 列不一致。
    • AvailableRentBikes + AvailableReturnBikes 在同一站內不是固定值（可能因車柱故障等），不能直接當作站點容量。
    • UpdateTime 通常比 SrcUpdateTime 晚約 24 秒，但 3,663 列早幾秒，最大相差約 2.5 小時；時間分析以 SrcUpdateTime 為準。
  • Definition for each variable:
    • 定義取自 TDX OAS 規格（見 raw codebook），「本檔處理」欄記錄 處理程式 所做的改變；數值範圍來自下方 Summary Stats 的實際輸出。

    candidate <- parent
  }

project_file <- function(relative_path, area, must_exist = TRUE) {
  # Exact project-relative paths only; no first-file search or OS-root /data path.
  parts <- strsplit(relative_path, "/", fixed = TRUE)[[1]]
  if (grepl("^(/|~|[A-Za-z]:)", relative_path) || ".." %in% parts ||
      grepl("<", relative_path, fixed = TRUE) ||
      !startsWith(relative_path, paste0("data/", area, "/"))) {
    stop("Replace the placeholder with an exact path inside data/", area, "/: ", relative_path)
  }
  path <- file.path(PROJECT_ROOT, relative_path)
  if (must_exist && (!file.exists(path) || dir.exists(path))) stop("Input file not found: ", path)
  # Resolve existing ancestors to reject a path that leaves the project via a symlink.
  ancestor <- path
  while (!file.exists(ancestor)) ancestor <- dirname(ancestor)
  resolved <- normalizePath(ancestor, winslash = "/", mustWork = TRUE)
  allowed <- normalizePath(file.path(PROJECT_ROOT, "data", area), winslash = "/", mustWork = TRUE)
  if (!startsWith(allowed, paste0(PROJECT_ROOT, "/"))) {
    stop("data/", area, "/ resolves outside the project root.")
  }
  if (!identical(resolved, allowed) && !startsWith(resolved, paste0(allowed, "/"))) {
    stop("Resolved path leaves data/", area, "/: ", relative_path)
  }
  path
}

sha256_file <- function(path) {
  if (!requireNamespace("digest", quietly = TRUE)) {
    stop("Cannot verify input identity: digest is unavailable. Use an available SHA-256 implementation before loading data.")
  }
  digest::digest(file = path, algo = "sha256", serialize = FALSE)
}

verify_input_sha256 <- function(path, expected) {
  # Bind this run to the exact file inspected when the notebook was prepared.
  if (!is.character(expected) || length(expected) != 1L || is.na(expected) ||
      !grepl("^[0-9a-fA-F]{64}$", expected)) {
    stop("Fill the expected SHA-256 from the inspected input before loading data.")
  }
  actual <- sha256_file(path)
  if (!identical(actual, tolower(expected))) stop("Input changed: identify the new version before loading ", basename(path), ".")
  actual
}
